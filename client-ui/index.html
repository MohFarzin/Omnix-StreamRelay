How to set up

1. Video (OBS / Aitum)

  1. Open Connection → Show details and copy Server + Main key.
  2. OBS → Settings → Stream → Custom · auth OFF.
  3. For 9:16, use the same Server with the Vertical key in Aitum.
  4. Add Destinations (YouTube / Twitch / Kick), paste each platform’s stream key, turn On once. Leave them On — stop/start OBS only; the relay auto-reconnects (no Off/On each time).
  5. Output → Advanced: Rate Control CBR, Keyframe Interval 2 (Twitch/Kick buffer if this is 0/auto/4+; YouTube still OK).

2. Chat bot (optional)

Chat is separate from video. In the game panel → your server → Startup variables, then restart:

  • Twitch: TWITCH_CHANNEL + TWITCH_ACCESS_TOKEN
  • YouTube chat: YOUTUBE_LIVE_CHAT_ID + API key or OAuth token
  • Kick chat: KICK_CHANNEL (+ optional KICK_ACCESS_TOKEN to reply)

After restart, Live chat shows which platforms are connected. Commands & welcome work on connected chats.

3. Kick / Twitch buffer tip

Paste Kick’s Server URL + key from Kick Creator. Keep OBS ≤ 8000 kbps CBR and keyframe = 2. YouTube often looks fine with longer keyframes; Twitch/Kick do not.
